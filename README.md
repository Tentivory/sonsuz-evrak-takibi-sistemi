# Sonsuz Evrak Takibi Sistemi

## Resmi Açıklama

**Türkiye Cumhuriyeti Dijital Bürokrasi Müdürlüğü** tarafından geliştirilen bu sistem, modern devlet yönetiminin en büyük sorununa çözüm getirmektedir: **Kaybolan Evraklar**.

Artık hiçbir belge kaybolmayacak. Çünkü bu sistem, belgelerinizi öylesine dikkatli takip eder ki, onları asla bulamazsınız. Bu, bilimin zaferidir.

### Özellikler

- **Sonsuz Takip**: Evrakınız asla sonuçlanmaz. Bu, sürekliliğin garantisidir.
- **Rastgele Departman Sevki**: Evrakınız her seferinde farklı bir birime gider. Eğitim için idealdir.
- **Geri Giden İlerleme Çubuğu**: Gerçekçiliği artırmak için ilerleme bazen geriye gider. Bürokrasiye sadık.
- **Kaybolma Uyarıları**: Sistem, evrakın kaybolduğunu size önceden bildirir. Şeffaflık!
- **Resmi Damga**: Her çıktının sonunda onay damgası bulunur.

### Kurulum

1. Python 3 yüklü olsun (zaten herkeste var, değil mi?).
2. Bu repoyu klonlayın.
3. `python sonsuz_evrak.py` komutunu çalıştırın.
4. Adınızı girin ve bekleyin. Çok bekleyin.

### Kullanım Örneği

```bash
$ python sonsuz_evrak.py
=== SONSUZ EVRAK TAKİBİ SİSTEMİ v1.0 ===
...
Evrak 123456, Kayyum Ofisi biriminde 'Kayboldu' durumundadır.
```

### Katkıda Bulunma

Lütfen katkıda bulunmayın. Sistem zaten mükemmel. Yeni özellik eklemek bürokrasiyi bozar.

Eğer illa isterseniz, bir issue açın. O da kaybolur.
